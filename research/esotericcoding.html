Esoteric coding languages are programming languages that are designed to be weird, hard to use, or charming in some way. Karen Ann introduced me to this concept (and to coding in general!) and I find the Esolang website, which categorises all these languages, is a pretty fabulous rabbit hole to go down. This also links into my explorations of magic and wonder being created, through the idea of Post-Internet Magic, which suggests we can view technology as this mysterious thing which has become so advanced, as to be magical. In this kind of thinking, writing code is kind of like writing a recipe for a magic spell or potion. One way that this can become more visual is through a kind of concrete poetry. This would involve formatting your code to form a visual picture. See also wireframe and ASCII graphics.
